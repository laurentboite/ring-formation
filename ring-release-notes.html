RING 10.0.0 — New for this release

RING DataBrowser UI Theming

DataBrowser supports UI theming: custom logo and brand colors configurable by administrators.

RING-52842

RING DataBrowser replaces S3Browser

Starting with RING 10, Data Browser becomes the default interface for S3 object storage, replacing the legacy S3 Browser. Improved lazy loading, native themes.

RING-51037

RING Scaldisk supports NVMe

Scaldisk now supports full NVMe platforms. Commands remain the same, with a new required flag --data or --index.

RING-52702

RING Enhanced SProxyd Dashboards (L2 & L3)

SProxyd dashboards now include two additional investigation levels (levels 2 and 3) for deeper diagnostics.

RING-52054
Orange · RD-910

RING RHEL 9.6 Support (since 9.5.2.1)

A RHEL 9.6 minor-version installer is now shipped alongside the generic RHEL 9 installer.

RING-53246

RING Fixed UID 490 for the scality user

The scality user now uses fixed UID 490 (range 200-499), reducing the risk of collision with other users.

RING-39356
KB · NFI-65

S3C Improved S3C Metadata Write Cache

The S3 Metadata service handles metadata traffic spikes more efficiently. A new optional queue mechanism protects the backend under extreme conditions (prevents HTTP 500 errors).

S3C-10879
Iron Mountain · RD-1333

S3C S3 Bucket Server Access Logging

S3 Connector supports the S3 bucket access logging API: access logs from one bucket are sent to another bucket in the same account. Simplifies auditing and analysis.

S3C-9428
Core42

S3C Operations Log Metadata Backup Management

Backup monitoring per Raft session, new compressed format, reformatting of existing chunks, removal of excess replicas.

S3C-11058
Mediahuis · RD-521

S3C Improved Bucket Logging

Bucket logging can now trace: ACL, lifecycle expiration events, replication events, rate limiting operations, TLS version, and Cipher Suite.

S3C-10819

S3C RocksDB Metadata Backend by Default

S3 Connector Metadata uses RocksDB as the new storage engine (replacing LevelDB). Better performance and scalability. Per-bucket migration available, hybrid environment supported.

S3C-10214

S3C S3C Analytics ClickHouse Node Removal

New capability to remove a node from the S3C Analytics ClickHouse cluster, simplifying hardware refresh and server migrations.

S3C-10082
Interpol · RD-1498

S3C S3 Bucket Rate Limiting

Request rate control per bucket: global or per-bucket limits. Requests exceeding the limit are rejected with a configurable error code. Protects against saturation and guarantees SLA.
